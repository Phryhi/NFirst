# NFirst

API em desenvolvimento em ASP.NET Core para processamento de arquivos XML de notas fiscais.

## Objetivo

O projeto tem como objetivo receber arquivos XML de notas fiscais, analisar seus dados e identificar quais notas são válidas, quais são NFC-e e se possuem CPF do consumidor. A partir dessas informações, a API deverá calcular o valor de crédito correspondente e retornar os resultados em formato json, facilitando a doação dessas notas fiscais para organizações de caridade.

## Tecnologias

- C#
- ASP.NET Core
- .NET 8
- Swagger
